# Agenda seed
<!-- Ordered bias for the facilitator — framework links + rough timeboxes. Not a mandate. -->
1. [[how-might-we]] — ~25m — reframe "why won't clinicians use this" into HMW stems (see
   prompt-pack.md) that first distinguish alert fatigue, click burden, and liability concerns
   from each other.
2. [[crazy-8s]] — ~20m — sketch concrete interventions against the strongest 2–3 HMW stems.
3. [[dot-voting]] — ~10m — converge the sketch pile to the top 2–3 candidate interventions.
4. [[bet-brief]] — ~30m — write up each shortlisted intervention as a one-page bet, with
   added-clicks/minutes-per-encounter as an explicit line, not an afterthought.
5. [[premortem]] — ~25m — pressure-test the leading bet, specifically against the pre-cleared
   non-negotiable liability/documentation requirements from the session's Constraints.
6. [[commitment-round]] — ~20m — named rollout owner, first concrete action, and a 90-day
   check-in date.
