# Agenda seed
<!-- Ordered bias for the facilitator — framework links + rough timeboxes. Not a mandate. -->
1. [[how-might-we]] — ~30m — reframe "how do we replace this funding" into HMW stems (see
   prompt-pack.md), each explicitly tagged as mission-fit, funder-fit, or both.
2. [[crazy-8s]] — ~20m — rapid-fire funding/program sketches against the strongest 2–3 HMW
   stems.
3. [[dot-voting]] — ~15m — converge the sketch pile to the 2–3 strongest funding bets.
4. [[bet-brief]] — ~35m — write up each shortlisted bet: the case for it, the funder or program
   it targets, the near-term ask.
5. [[premortem]] — ~30m — pressure-test the leading bet, specifically for mission drift and for
   what happens if this funding source also proves unreliable in three years.
6. [[commitment-round]] — ~25m — named owner, first concrete ask or action, and a date.
