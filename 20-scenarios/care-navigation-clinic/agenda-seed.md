# Agenda seed
<!-- Ordered bias for the facilitator — framework links + rough timeboxes. Not a mandate. -->
1. [[how-might-we]] — ~30m — reframe "why do patients no-show" into HMW stems (see
   prompt-pack.md) that treat drop-off as a system design question, not a patient-compliance
   one.
2. [[crazy-8s]] — ~20m — sketch concrete interventions against the strongest 2–3 HMW stems.
3. [[dot-voting]] — ~15m — converge the sketch pile to the 2–3 strongest candidate gaps to
   target, with front-desk/scheduling votes weighted equally to leadership's.
4. [[bet-brief]] — ~35m — write up each shortlisted gap as a one-page bet: the pathway it
   targets, the patient segment, the resourcing ask.
5. [[premortem]] — ~30m — pressure-test the leading bet, specifically for whether it assumes
   data the system doesn't actually have.
6. [[commitment-round]] — ~25m — named owner, first concrete action, and a date to check
   whether the targeted gap actually closed.
