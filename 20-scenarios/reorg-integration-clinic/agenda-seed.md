# Agenda seed
<!-- Ordered bias for the facilitator — framework links + rough timeboxes. Not a mandate. -->
1. [[how-might-we]] — ~25m — reframe "whose process wins" into HMW stems scoped to outcomes
   (what the merged team needs to be able to do), not to either legacy process by name.
2. [[note-and-vote]] — ~30m — for each overlapping area on the list, silent-write a position
   and reason before any open discussion, so structural power in the room doesn't anchor the
   conversation before quieter voices are heard.
3. [[gradients-of-agreement]] — ~40m — run the decide gate per overlapping area on the 8-point
   scale instead of a binary vote; a 5–6 is a real signal to capture, not overridden agreement.
4. [[premortem]] — ~30m — pressure-test the leading integration bets, specifically for the
   scenario where the losing-side process was actually load-bearing in a way the room
   underweighted.
5. [[commitment-round]] — ~30m — per bet: named transition owner, first concrete action, date.
   Explicitly log anything parked as out-of-scope for this session rather than letting it drop
   silently.
