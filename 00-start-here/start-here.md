# Start here

This repo is an Obsidian vault, a Cursor workspace, and a Claude Code project — same files.
`CLAUDE.md` is the constitution; read its §1–§4 once and you understand the whole system.

**Run a lab:** `/new-lab <scenario> <YYYY-MM-DD> <slug>` → fill constraints in the session
hub → facilitator drafts the agenda → `/capture` during → `/distill` → `/provoke` →
`/synthesize` → `/retro` → `/export`. Run `/weave` whenever the graph should catch up.
