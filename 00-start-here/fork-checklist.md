# Fork checklist

1. Fork/clone; open the **repo root** in Obsidian; accept the prompt to enable Dataview
   (optional — nothing breaks without it).
2. Skim `CLAUDE.md` §1–§4 and §11 (scenario contract).
3. Author your scenario: copy `20-scenarios/_template/` → `20-scenarios/<your-slug>/`,
   rename `scenario-hub.md` → `<your-slug>.md`, fill it in.
4. Extend `10-frameworks/` and `90-meta/taxonomy.md` vocab as needed (add, don't rename).
5. `/new-lab <your-slug> <date> <session-slug>` and run the loop.
6. Before sharing anything externally: `/export --anonymize` only.
