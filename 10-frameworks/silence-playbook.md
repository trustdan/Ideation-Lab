# Silence / low-engagement playbook
## When to use
You ask the room a question and get 10–15+ seconds of nothing — no hands, no chat, cameras
going dark. Before intervening, check: was that one clear question, or three stacked
together? Is executive presence suppressing psychological safety? Did you actually wait the
full 7 seconds before rescuing the silence?
## Steps
1. Count to 7 silently before doing anything — what feels like an eternity to you is normal
processing time for them. 2. Lower the stakes: swap the open verbal ask for something
low-risk ("raise a hand if…", "one word in the chat"). 3. Pair up for 60–90s before returning
to the full room — a mini `[[note-and-vote]]`. 4. If still stuck, name it directly: "are we
quiet because the question's unclear, because we need more info, or because people are
tired?"
## Output
Re-engaged room; no file artifact.
## Facilitation notes
Never answer your own question out of discomfort with the silence, never cold-call someone
when safety already looks low, and never guilt the room ("come on, I need some interaction
here"). Prevent this upstream: avoid open plenary asks like "any comments?" — always give a
silent writing prompt before asking for verbal sharing.
