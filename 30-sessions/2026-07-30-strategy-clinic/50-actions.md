# Decisions & actions

## Decisions

**Decision 1 — pre-checks before either kill test, not parallel kill tests as first drafted.**
The synthesis's recommendation was to run Bet A's and Bet B's kill tests in parallel. All
three provocateur challenges converged on the same objection: several cheaper, faster,
disqualifying facts were never pulled before that recommendation was written (the flagship
recompete's own timeline, the target agency's real budget window, whether the incumbent
integrator has an actual accreditation gap, and this company's real bid/no-bid history with
its current prime). Criteria: run the cheapest test that could kill a bet outright before
spending BD capacity on the more expensive test already designed for it. Source:
[[30-sessions/2026-07-30-strategy-clinic/30-ideas/challenge-recommendation|challenge-recommendation]],
[[30-sessions/2026-07-30-strategy-clinic/30-ideas/challenge-expand-into-an-adjacent-mission-or-offering|challenge: Theme 2]],
[[30-sessions/2026-07-30-strategy-clinic/30-ideas/challenge-reduce-single-prime-exposure-through-a-second-channel|challenge: Theme 1]].

**Decision 2 — Theme 3 (cleared-talent bench) proceeds regardless, as an ops initiative, not
a competing strategic bet.** Confirmed at the decide gate and unchanged by provocation: it has
its own accepted challenge
([[30-sessions/2026-07-30-strategy-clinic/30-ideas/structural-ops-bets-need-different-criteria-than-bd-capture-bets|structural-vs-capture]])
already reclassifying it out of the A/B competition. Source: [[30-sessions/2026-07-30-strategy-clinic/40-synthesis|40-synthesis]].

**Decision 3 — follow-through gets an independent check, not just an owner and a date.**
`challenge-recommendation` named the "owner + date" fix itself as unproven (three prior debrief
recommendations may already have had both, per [[30-sessions/2026-07-30-strategy-clinic/30-ideas/loss-debriefs-recommendations-go-unactioned|the pattern it names]]) and reframed toward a
recurring checkpoint owned by someone with no stake in either bet. Criteria: an external
forcing function beats a self-policed one. Source: [[30-sessions/2026-07-30-strategy-clinic/30-ideas/challenge-recommendation|challenge-recommendation]] (Reframes).

**Parked, not dropped:** [[30-sessions/2026-07-30-strategy-clinic/30-ideas/sell-sustainment-data-analytics-not-labor|sustainment data analytics]] — real verbal support at the
decide gate, no dot-vote backing; revisit next quarterly session.
