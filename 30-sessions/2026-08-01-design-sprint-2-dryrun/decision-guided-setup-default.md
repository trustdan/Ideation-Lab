# Decision: Guided setup with always-visible skip becomes the default prototype path

## Options considered
- Guided setup with a pre-selected default and an always-visible skip control (Linear-inspired).
- Blank workspace with contextual tips and no imposed setup sequence.

## Outcome
Build the guided-setup direction as the primary prototype for Friday'''s test, with skip
continuously visible. The blank-workspace direction is not discarded: it becomes the required
fallback surface for users who skip guidance, per the bypass behavior observed in Interview 2.

## Rationale
The storyboard critique dot-vote scored guided setup 6-2. The provoke pass explicitly challenged
this as team preference rather than validated user preference (assumption A1 in the challenge
note), so this decision is scoped as a prototype commitment to test, not a final validation —
the challenge note'''s kill tests remain the bar for treating it as confirmed.
