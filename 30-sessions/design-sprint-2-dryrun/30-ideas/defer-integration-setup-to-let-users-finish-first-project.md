# New users should be able to complete their first project without being blocked by integration setup

Forcing integration setup before a first project is completed creates an unnecessary early exit point.

## Notes

- Originated as an HMW prompt during the warm-up exercise.
- HMW phrasing: "How might we let a new user finish their first project without hitting the integration-setup step?"
- Points toward deferring or making optional the integration-setup gate in the new-user flow.
