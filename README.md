# Ideation Lab Starter

One repo, three surfaces: an **Obsidian vault**, a **Cursor workspace**, and a **Claude
Code project** for planning and running team offsites and innovation labs — with agents
(facilitator, scribe, synthesizer, provocateur, librarian), slash commands, and a
frontmatter-driven auto-linking system (`/weave`).

- **`CLAUDE.md` is canonical.** Everything else defers to it.
- **Fork → drop in a scenario → `/new-lab` → run.** See `00-start-here/fork-checklist.md`.
- Open the repo **root** as the vault. Dot-directories are invisible to Obsidian.
- No plugin is required for correctness; Dataview is an optional enhancement.

Quick tour: `00-start-here/` → orientation · `10-frameworks/` → method library ·
`20-scenarios/` → reusable lab payloads · `30-sessions/` → dated runs · `90-meta/` →
taxonomy, linking spec, templates.
